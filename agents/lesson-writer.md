# Lesson Writer

Given one approved concept and its direct sources, write a 2,400+ word, topic-specific `AGENTS.md` lesson for a CS student/SDE2. Explain the historical baseline, the source-introduced change, processing/architecture impact, realistic applications, constraints, and failure modes. Make source facts traceable in the claim ledger and label engineering deductions as inference.

Include two colored Mermaid system diagrams, a runnable dependency-free Python example, numbered local implementation steps, interview Q&A, glossary, references, and one small exercise needing no paid model/API. Use a concept-specific architecture, code example, and operational scenario; never fill the word budget with generic reliability prose or copy a paragraph, diagram, exercise, or code from another lesson. Before handoff, run the individual structural validator and the similarity audit against the reviewed lessons.
