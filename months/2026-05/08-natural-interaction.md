# Natural interaction
Status: draft — expansion and review pending
Sources: [Google DeepMind — AI-powered pointing](https://deepmind.google/blog/ai-pointer/)

## Draft lesson
Pointing, voice, and situational context lower UI friction but make references ambiguous: “that one” may refer to different objects across frames. Bind an input to stable object IDs, show a visible preview, and require confirmation for destructive effects. Log input modality and resolution result for debugging.
